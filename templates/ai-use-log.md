## 좋은 프롬프트 체크 (4요소 + 검증)

- [ ] 역할·맥락: 나는 누구이고 어떤 환경인가 (Colab, 사용 라이브러리)
- [ ] 요구사항: 입력·출력의 모양, 규칙, 경계
- [ ] 제약 조건: 원본 불변, `except:` 금지, 가변 기본값 금지 등
- [ ] 출력 형식: 코드 + 설명 + 테스트
- [ ] 검증 조건: "합계가 총액과 같아야 함", "결과 shape는 (n,)" 처럼 확인할 기준

## 공개 문장 예시

> 13주차 대시보드 초안 코드를 ChatGPT로 생성했다. 요일 순서(가나다순 → 월~토), y축 시작점(0), 요일별 합계 → 일평균 계산을 직접 수정했고, 결론 문장의 "기온이 매출을 올린다"는 인과 표현을 삭제했다. 수정한 코드는 작은 데이터 테스트 3개로 확인했다.
