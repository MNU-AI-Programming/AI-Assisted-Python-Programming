# 중간 실기 — 성적 분석 미니 프로젝트 (8주차)

## 목적

1~7주차에서 배운 문자열·제어문·자료구조·함수·파일·예외·클래스를 **하나의 문제 해결 과정**으로 통합할 수 있는지 확인합니다. 결과뿐 아니라 **설계, 검증, 설명**을 함께 평가합니다.

## 진행 방식

| 항목 | 내용 |
|---|---|
| 일시 | 8주차 수업 시간 (안내 15분 + 실기 90분 + 제출 확인 15분) |
| 문제 | [`weeks/week08/assignment.ipynb`](../weeks/week08/assignment.ipynb) 4문제 + 기술 메모 |
| 데이터 | [`students.csv`](../datasets/students.csv) (80명 가상 데이터) |
| 도구 | Python 표준 라이브러리 (`csv`, `pathlib` 등). **pandas는 사용하지 않습니다.** |
| AI 사용 | 교수자가 실기 당일 공지 (예: 개념 질문만 허용 / 전면 허용 + 기록). 사용했다면 기술 메모에 기록 |
| 제출 | `midterm_학번_이름.ipynb` (다시 시작 및 모두 실행 후) |

## 문제 구성 (100점)

| 문제 | 내용 | 배점 | 관련 주차 |
|---|---|---:|---|
| 1 | `load_students`: CSV 읽기, 형 변환, 규칙 위반 행 건너뛰기 | 20 | 6 |
| 2 | `total_score` · `final_grade` · `dept_summary`: 성적 규정과 학과별 요약 | 25 | 3, 4, 5 |
| 3 | `GradeBook` 클래스: 찾기, 상위 n명, 등급 분포, 위험 학생 | 25 | 4, 7 |
| 4 | `write_report`: 정해진 형식의 보고서 파일 저장 | 20 | 2, 6 |
| 5 | 기술 메모: 설계·테스트·AI 사용·한계 | 10 | 전체 |

## 성적 규정

| 항목 | 규정 |
|---|---|
| 총점 | 중간 30% + 기말 40% + 과제 30%, 소수 첫째 자리 반올림 |
| 과제 미제출 | 빈 칸 → `None`, 총점 계산에서는 0점 |
| 등급 | 90 이상 A, 80 이상 B, 70 이상 C, 60 이상 D, 그 외 F |
| 출석 | 16회 중 12회 미만이면 총점과 관계없이 F |

## 준비 방법

1. [8주차 실습 노트북](../weeks/week08/practice.ipynb)의 **빠른 점검 6문항**을 AI 없이 다시 풀기
2. 같은 노트북의 **모의 실기(동아리 회비 관리)** 를 5단계(요구사항→설계→구현→테스트→메모)로 풀기
3. 1~7주차 과제 노트북의 AI 협업 문제를 **AI 없이** 다시 작성해 보기

## 평가

[중간 실기 루브릭](../rubrics/midterm-rubric.md)을 따릅니다. 자동 확인 결과는 참고 자료이며, 채점자는 다른 입력으로도 실행해 보고 코드를 직접 읽습니다.

## 유의 사항

- 결과값을 직접 써 넣은(하드코딩) 코드는 해당 문제의 기능 점수를 받지 못합니다.
- `except:`처럼 모든 오류를 삼키는 코드는 품질 점수에서 감점합니다.
- 제출한 코드는 한 줄씩 설명할 수 있어야 하며, 필요하면 구술로 확인합니다.
- 공지된 범위를 넘어 AI를 사용하거나, 사용 사실을 숨기면 부정행위로 처리합니다.
