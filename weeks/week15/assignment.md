# Week 15 과제 — 최종 프로젝트 발표와 재현성

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MNU-AI-Programming/AI-Assisted-Python-Programming/blob/main/weeks/week15/assignment.ipynb)

## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 환경과 데이터 지문 기록 | 2 |
| 2 | 결과표를 Markdown으로 | 2 |
| 3 | 시드가 있는 부트스트랩 신뢰구간 | 3 |
| 4 | README 생성기와 내 프로젝트 README (AI 협업) | 3 |

### 문제 1. 환경과 데이터 지문 기록 (2점)

라이브러리 버전과 데이터 파일의 행 수·열·MD5 해시를 기록하는 함수를 만듭니다.

### 문제 2. 결과표를 Markdown으로 (2점)

외부 라이브러리 없이 DataFrame을 README에 붙일 Markdown 표 문자열로 바꿉니다.

### 문제 3. 시드가 있는 부트스트랩 신뢰구간 (3점)

시드를 고정한 부트스트랩 95% 신뢰구간을 구하고, 시험 주간과 평상시의 일별 주문 수 구간을 비교합니다.

### 문제 4. README 생성기와 내 프로젝트 README (AI 협업) (3점)

정해진 절 순서의 README를 만드는 함수를 작성하고, 내 최종 프로젝트의 README 초안과 AI 활용 공개, 한 학기 성찰을 씁니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week15_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
