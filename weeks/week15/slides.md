# 재현성이란?

> **다른 사람이** (또는 한 달 뒤의 내가) **같은 코드와 데이터로 같은 결과**를 얻을 수 있는가?

- 내 화면에서 한 번 돌아간 것 ≠ 재현 가능
- 재현 가능해야 결과를 **믿고 검증**할 수 있다
- 실무 · 연구 · 수업 모두에서 기본 요건

---

# 재현성이 깨지는 이유

| 원인 | 막는 법 |
|---|---|
| 셀 실행 순서 | **다시 시작 및 모두 실행** |
| 절대 경로 `/content/drive/MyDrive/...` | 상대 경로 · 공개 URL |
| 난수 | `default_rng(42)`, `random_state=42` |
| 라이브러리 버전 | 버전 기록, `requirements.txt` |
| 데이터가 바뀜 | 데이터 **지문**(행 수 · 해시), 출처 · 날짜 |
| 손으로 고친 데이터 | 정제도 **코드로** |

---

# 재현성 셀 (노트북 맨 위)

```python
SEED = 42
rng = np.random.default_rng(SEED)

def fingerprint(path):
    raw = Path(path).read_bytes()
    return {"file": Path(path).name, "rows": raw.count(b"\n") - 1,
            "md5": hashlib.md5(raw).hexdigest()[:12]}

print(f"Python {sys.version.split()[0]} / pandas {pd.__version__} ...")
print("데이터:", fingerprint(get_data("cafe_sales.csv")))
```

결과가 달라지면 → **버전? 데이터? 시드?** 를 바로 비교

---

# 시드가 없으면

```python
np.random.default_rng().choice(values, 3)       # 실행마다 다름
np.random.default_rng(42).choice(values, 3)     # 항상 같음
df.sample(3, random_state=42)                   # 항상 같음
```

부트스트랩 · 표본 추출 · 데이터 나누기처럼 **무작위가 들어가는 모든 곳**에 시드

# 발표 팁

- 그래프 한 장에 **메시지 하나** — 제목이 곧 말할 문장
- 숫자는 **비교와 함께**: "40%"보다 "점심 3시간이 하루의 40%"
- 코드 화면은 꼭 필요할 때만, 짧게
- 리허설로 시간을 재고 **4분 30초**에 끝내기
- 질문에 모르면 "확인해 보겠습니다" — 추측으로 답하지 않기

# AI 결론 검증

| AI 문장 | 근거 | 판정 |
|---|---|---|
| "점심 매출이 하루의 절반 이상" | 39.2% | 과장 |
| "기온 상승이 아이스 수요를 증가시킨다" | 상관만 확인 | 인과 주장 |
| "25℃ 이상인 날 아이스 비율이 가장 높았다(6일 기준)" | 구간별 표 | 근거 · 표본 명시 |

결론 문장마다 **어느 표 · 그래프가 근거인지** 짝지을 수 있어야 한다
