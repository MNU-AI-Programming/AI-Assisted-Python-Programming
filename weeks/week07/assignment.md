## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 은행 계좌 클래스 | 2 |
| 2 | 도형 상속과 다형성 | 2 |
| 3 | 할 일 목록 클래스 | 3 |
| 4 | 스터디룸 예약 시스템 (AI 협업) | 3 |

### 문제 1. 은행 계좌 클래스 (2점)

입금·출금·거래 기록·`__str__`을 가진 `BankAccount`를 만들고, 잘못된 금액과 잔액 부족은 상태를 바꾸지 않고 `ValueError`를 냅니다.

### 문제 2. 도형 상속과 다형성 (2점)

`Rectangle`, `Rectangle`을 상속한 `Square`, `Circle`을 만들고 `total_area`가 종류 검사 없이 넓이 합을 구하게 합니다.

### 문제 3. 할 일 목록 클래스 (3점)

번호 부여, 완료 처리, 미완료·마감 지난 목록, `@property` 진행률을 가진 `TodoList`를 만듭니다.

### 문제 4. 스터디룸 예약 시스템 (AI 협업) (3점)

운영 시간·중복 예약·하루 한도 규칙을 지키는 예약/취소 시스템을 만들고, 시스템과 학생 양쪽 상태를 함께 갱신하는지 검증합니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week07_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
