# Week 11 과제 — 데이터 정제 · 변환 · 집계

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MNU-AI-Programming/AI-Assisted-Python-Programming/blob/main/weeks/week11/assignment.ipynb)

## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 학과명 표준화 | 2 |
| 2 | 코딩 시간 숫자 변환과 이상값 | 2 |
| 3 | 설문 정제 파이프라인 | 3 |
| 4 | 단과대학 요약과 피벗 (AI 협업) | 3 |

### 문제 1. 학과명 표준화 (2점)

공백과 줄임말을 정리해 표준 5개 학과명으로 통일하고, 그 밖의 값은 "기타"로 바꿉니다.

### 문제 2. 코딩 시간 숫자 변환과 이상값 (2점)

문자열에서 첫 숫자를 꺼내 실수로 바꾸고, 0~상한 밖의 값은 자르지 않고 결측으로 처리합니다.

### 문제 3. 설문 정제 파이프라인 (3점)

요일 열을 포함한 8개 열로 정제하고, 표기 통일 후 중복을 제거하며 원본을 바꾸지 않습니다.

### 문제 4. 단과대학 요약과 피벗 (AI 협업) (3점)

`merge`로 단과대학별 요약을 만들되 행 수 변화를 검사하고, 학년×AI 사용 만족도 피벗을 만듭니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week11_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
