# Week 01 과제 — AI 협업 코딩과 Colab 시작

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MNU-AI-Programming/AI-Assisted-Python-Programming/blob/main/weeks/week01/assignment.ipynb)

## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 자기소개 변수 만들기 | 2 |
| 2 | 온도 변환 함수 | 2 |
| 3 | 버그 고치기: 수강 시간 요약 | 3 |
| 4 | AI와 함께 만드는 자기소개 카드 | 3 |

### 문제 1. 자기소개 변수 만들기 (2점)

`name`, `major`, `year`, `goal` 변수를 자료형 조건에 맞게 만듭니다.

### 문제 2. 온도 변환 함수 (2점)

`c_to_f(c)`, `f_to_c(f)`를 완성하고 소수 첫째 자리까지 반올림해 돌려줍니다. −40도, 왕복 변환까지 확인합니다.

### 문제 3. 버그 고치기: 수강 시간 요약 (3점)

버그 3개가 있는 `study_summary(weeks, hours_per_week)`를 고쳐 `"총 30시간 (1,800분)"` 형식을 돌려주게 하고, 버그 기록표를 작성합니다.

### 문제 4. AI와 함께 만드는 자기소개 카드 (3점)

4요소 프롬프트를 작성해 AI와 함께 `make_card(name, major, goal)`을 만들고, 자동 확인으로 검증한 뒤 AI 활용 기록을 남깁니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week01_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
