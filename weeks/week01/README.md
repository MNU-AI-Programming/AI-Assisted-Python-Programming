## 학습 목표

- Colab에서 셀을 실행하고 실행 순서가 결과를 바꾼다는 것을 설명한다.
- 변수·자료형·형 변환·f-string으로 간단한 출력 프로그램을 만든다.
- 오류 메시지를 마지막 줄부터 읽고 원인을 찾아 고친다.
- 4요소 프롬프트로 AI에게 묻고, 받은 코드를 정상·경계·잘못된 입력으로 검증한다.
