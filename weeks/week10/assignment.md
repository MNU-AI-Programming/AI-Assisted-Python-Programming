# Week 10 과제 — pandas로 데이터 불러오기와 탐색

## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 데이터 개요 함수 | 2 |
| 2 | 조건 필터와 정렬 | 2 |
| 3 | 총점·등급 열 추가 | 3 |
| 4 | 학과별 탐색 보고 (AI 협업) | 3 |

### 문제 1. 데이터 개요 함수 (2점)

행·열 수, 결측이 있는 열, 숫자 열, 문자열 열의 고유값 개수를 딕셔너리로 돌려줍니다.

### 문제 2. 조건 필터와 정렬 (2점)

학과·학년·기말 조건으로 학생을 고르고, 기말 내림차순·학번 오름차순으로 정렬해 인덱스를 다시 매깁니다.

### 문제 3. 총점·등급 열 추가 (3점)

원본을 바꾸지 않고 총점과 등급(출석 규정 포함) 열을 추가한 새 DataFrame을 만들고, 8주차 결과와 일치하는지 확인합니다.

### 문제 4. 학과별 탐색 보고 (AI 협업) (3점)

학과별 학생 수·기말 평균·과제 결측·출석 미달·통과율 표를 만듭니다. AI 코드의 count/size 혼동과 체인 인덱싱을 확인해 기록합니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week10_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
