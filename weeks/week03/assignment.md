## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 학점 판정과 경계값 | 2 |
| 2 | 목포대학 게임 | 2 |
| 3 | 장학 판정과 집계 | 3 |
| 4 | 저축 목표 계산기 – 무한 반복 막기 (AI 협업) | 3 |

### 문제 1. 학점 판정과 경계값 (2점)

`grade(score)`를 A+~F와 "오류"로 판정하고, 제공된 경계값 표 외에 **직접 고른 경계값 테스트 4개**를 추가합니다.

### 문제 2. 목포대학 게임 (2점)

1부터 n까지 3의 배수는 "목포", 5의 배수는 "대학", 15의 배수는 "목포대학"으로 바꾼 리스트를 돌려줍니다.

### 문제 3. 장학 판정과 집계 (3점)

우선순위가 있는 4단계 장학 판정 함수와, 학생 목록의 장학별 인원을 세는 함수를 만듭니다.

### 문제 4. 저축 목표 계산기 – 무한 반복 막기 (AI 협업) (3점)

이자와 월 저축으로 목표 도달 개월 수를 계산합니다. 이미 도달(0)과 도달 불가(-1, 600개월 상한)를 처리하고, 무한 반복 위험을 프롬프트와 테스트로 다룬 과정을 기록합니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week03_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
