## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 단어 빈도 세기 | 2 |
| 2 | 두 수강반 비교 | 2 |
| 3 | 학과별 성적 요약 | 3 |
| 4 | 순위와 필터 – 원본을 지켜라 (AI 협업) | 3 |

### 문제 1. 단어 빈도 세기 (2점)

`word_count(text)`가 소문자 통일과 문장부호 제거 후 단어별 등장 횟수 딕셔너리를 돌려줍니다.

### 문제 2. 두 수강반 비교 (2점)

중복 기록이 있는 두 명단을 집합으로 바꿔 공통·한쪽만·전체 인원을 딕셔너리로 돌려줍니다.

### 문제 3. 학과별 성적 요약 (3점)

레코드 리스트를 학과별로 묶어 인원·평균(소수 첫째 자리)·최고 득점자(동점이면 이름순)를 구합니다.

### 문제 4. 순위와 필터 – 원본을 지켜라 (AI 협업) (3점)

`top_n`과 `drop_below`를 원본을 바꾸지 않고 구현합니다. AI의 첫 코드가 연속 삭제·원본 변경 확인에서 실패했는지 기록합니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week04_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
