## 학습 목표

- 1~7주차의 문자열·제어문·자료구조·함수·파일·예외·클래스를 하나의 문제 해결 과정으로 통합한다.
- 요구사항 분석 → 설계 → 구현 → 테스트 → 기술 메모의 5단계로 문제를 해결한다.
- 규칙과 예외마다 테스트를 두고, 경계값과 원본 불변을 확인한다.
- 설계 이유·테스트·AI 사용·한계를 담은 1쪽 기술 메모를 작성한다.

## 이번 주 실습과 산출물

- **핵심 실습**: 모의 실기(동아리 회비 관리)와 중간 실기(성적 분석 미니 프로젝트)
- **산출물**: 중간 실기 노트북(`midterm_학번_이름.ipynb`)과 기술 메모
