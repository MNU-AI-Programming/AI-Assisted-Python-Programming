|---|---|---:|

### 문제 1. 가중 평균과 입력 검증 (2점)

`weighted_average(scores, weights)`가 가중 평균을 돌려주고, 길이 불일치·빈 리스트·합이 1이 아님·음수 가중치에서 `ValueError`를 냅니다.

### 문제 2. 비밀번호 강도 검사 (2점)

길이와 문자 종류(소문자·대문자·숫자·특수문자) 수로 "약함/보통/강함"을 판정합니다. 도우미 함수로 나누어 작성합니다.

### 문제 3. 텍스트 통계 함수 (3점)

공백 제외 글자 수, 단어 수, 문장 수, 평균 단어 길이를 딕셔너리로 돌려주며 빈 문자열과 연속 문장부호를 처리합니다.

### 문제 4. 테스트로 AI 버그 잡기 (AI 협업) (3점)

중앙값 규칙을 검사하는 `my_tests(fn)`의 테스트 케이스를 작성해 AI의 버그 함수 2개를 잡아내고, 올바른 `median`을 구현합니다.
