## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 초를 `HH:MM:SS`로 바꾸기 | 2 |
| 2 | 학번 분석하기 | 2 |
| 3 | 영수증 문자열 만들기 | 3 |
| 4 | 정확한 정산 함수 (AI 협업) | 3 |

### 문제 1. 초를 `HH:MM:SS`로 바꾸기 (2점)

`to_hms(sec)`가 `7384` → `"02:03:04"`처럼 항상 두 자리로 돌려주도록 `//`, `%`, `divmod`를 활용합니다.

### 문제 2. 학번 분석하기 (2점)

9자리 학번에서 입학년도·학과코드·번호를 슬라이싱으로 꺼내 `"2026학번 / 학과 12 / 34번"` 형식으로 돌려줍니다.

### 문제 3. 영수증 문자열 만들기 (3점)

`"메뉴:가격"`을 `/`로 이은 지저분한 문자열을 정리해 메뉴별 줄과 합계 줄을 가진 영수증 문자열을 만듭니다.

### 문제 4. 정확한 정산 함수 (AI 협업) (3점)

`split_exact(total, people, unit)`이 (일반 금액, 마지막 금액)을 돌려주며 합계가 항상 총액과 같도록 만듭니다. 규칙과 검증 조건을 담은 프롬프트를 기록합니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week02_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
