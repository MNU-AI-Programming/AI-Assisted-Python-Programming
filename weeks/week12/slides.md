# 한 행의 의미와 집계 단위

**한 행 = 주문 한 건의 메뉴 한 종류** (`qty` = 수량)

| 단위 | 계산 | 답하는 질문 |
|---|---|---|
| 주문 건수 | 행 수 | 얼마나 자주 주문되나 |
| 판매 수량 | `qty` 합 | 몇 잔 팔렸나 |
| 매출 | `unit_price × qty` 합 | 얼마나 벌었나 |

"인기 메뉴"는 무엇 기준인가? → **먼저 정한다**

# 파생 변수

```python
cafe["revenue"] = cafe["unit_price"] * cafe["qty"]
cafe["month"] = cafe["date"].dt.month
cafe["weekday"] = pd.Categorical(
    cafe["date"].dt.dayofweek.map(dict(enumerate("월화수목금토일"))),
    categories=list("월화수목금토"), ordered=True)
cafe["hour"] = cafe["time"].str[:2].astype(int)
cafe["daypart"] = pd.cut(cafe["hour"], bins=[7, 10, 13, 16, 19],

```

순서 있는 `Categorical` → 정렬 · 그래프가 **월화수…** 순서

# Q2. 요일: 합계 말고 일평균

daily = cafe.groupby("date").agg(revenue=("revenue", "sum"))

```

# 기온 구간별 비교

| 평균기온 | 일수 | 아이스 비율 | 일평균 매출 |
|---|---:|---:|---:|
| 10℃ 미만 | 23 | 26.0% | 140,565 |
| 10~15 | 28 | 41.4% | 151,229 |
| 15~20 | 19 | 53.3% | 156,553 |
| 20~25 | 19 | 71.9% | 144,632 |
| 25℃ 이상 | 6 | 81.3% | 168,017 |

아이스 비율은 **뚜렷이** 증가, 매출은 **뚜렷한 경향 없음**

---

# 상관 ≠ 인과

- 기온과 아이스 비율의 상관이 높다 → "기온이 **원인**"이라고 말할 수 있나?
- 같은 시기에 **계절, 시험 일정, 학사 일정**도 함께 바뀐다
- 이 데이터로 말할 수 있는 것: "**함께 변한다**"

| 말해도 되는 것 | 말하면 안 되는 것 |
|---|---|
| 기온이 높은 날 아이스 비율이 높았다 | 기온을 올리면 아이스가 팔린다 |
| 시험 주간 일평균 주문이 많았다 (10일) | 시험이 판매를 늘린다 |

---

# 발견 정리: 숫자 + 기준 + 한계

| 발견 | 근거 | 주의점 |
|---|---|---|
| 아메리카노·라떼가 매출의 40% 이상 | 메뉴별 매출 비중 | 한 학기 데이터 |
| 평일 점심, 특히 12시가 가장 바쁨 | 요일×시간대 일평균 | 일요일 휴무 |
| 기온↑ → 아이스 비율↑ (26% → 81%) | 상관 0.85, 구간 비교 | 상관이지 인과 아님 |
| 시험 주간 주문 증가 (34 → 41건) | 평일 비교 | 10일뿐 |

---

# AI 해석 검증

AI: "가장 인기 있는 메뉴는 아메리카노이며, **주문의 40% 이상**"
→ 실제: 건수 29.1% · 수량 28.9% · 매출 23.6% — **과장**, 기준도 없음

AI: "**3월 매출이 6월보다 훨씬 높으므로** 학기 초에 수요가 몰린다"
→ 6월은 20일까지(영업일 17일), **일평균은 6월이 더 높음**

AI: "기온이 오르면 매출 증가 → **가격 인상**"
→ 상관 0.1로 약함, 인과도 아님, 가격 효과는 알 수 없음

```
