# Week 12 과제 — 탐색적 데이터 분석과 프로젝트 기획

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MNU-AI-Programming/AI-Assisted-Python-Programming/blob/main/weeks/week12/assignment.ipynb)

## 과제 구성 (10점)

| 문제 | 내용 | 배점 |
|---|---|---:|
| 1 | 시간 파생 변수 만들기 | 2 |
| 2 | 요일 × 시간대 일평균 매출표 | 2 |
| 3 | 메뉴 매출 비중과 상위 80% 메뉴 | 3 |
| 4 | 기온 구간 분석 (AI 협업) + 프로젝트 제안서 | 3 |

### 문제 1. 시간 파생 변수 만들기 (2점)

날짜·시각에서 매출, 월, 요일, 시, 시간대 열을 만든 새 DataFrame을 돌려줍니다.

### 문제 2. 요일 × 시간대 일평균 매출표 (2점)

요일별 영업일 수로 나눈 일평균 매출 피벗을 월~토, 아침~저녁 순서로 만듭니다.

### 문제 3. 메뉴 매출 비중과 상위 80% 메뉴 (3점)

메뉴별 수량·매출·비중·누적 비중 표를 만들고 누적 80%에 처음 도달하는 메뉴까지 고릅니다.

### 문제 4. 기온 구간 분석 (AI 협업) + 프로젝트 제안서 (3점)

일별 매출·아이스 비율을 기온과 합쳐 구간별로 요약하고 병합 후 행 수를 검사합니다. AI 해석 문장 하나를 검증하고, 최종 프로젝트 제안서 초안을 작성합니다.

## 제출 방법

1. Colab에서 `assignment.ipynb`를 열고 **파일 → 드라이브에 사본 저장**을 누릅니다.
2. 파일 이름을 `week12_학번_이름.ipynb`로 바꿉니다.
3. `# TODO` 부분을 채우고 각 문제 아래 **자동 확인 셀**이 ✅인지 확인합니다.
4. 문제별 **AI 활용 기록**과 마지막 **성찰**을 작성합니다. AI를 쓰지 않았다면 "사용 안 함"이라고 씁니다.
5. **런타임 → 다시 시작 및 모두 실행** 후 오류가 없으면 `.ipynb` 파일을 LMS에 제출합니다.
