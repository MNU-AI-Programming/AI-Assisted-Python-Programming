# 교수자 운영 가이드

## 주차별 자료 구성

| 파일 | 용도 | 비고 |
|---|---|---|
| `weeks/weekNN/README.md` | 학습 목표, 2시간 흐름, 슬라이드–노트북 연결표 | LMS 주차 안내에 그대로 활용 |
| `weeks/weekNN/slides.md` / `slides.pdf` | Marp 슬라이드 (20~26장) | PDF는 `scripts/build_slides.sh`로 다시 생성 |
| `weeks/weekNN/practice.ipynb` | 수업 시간 실습 (Level 1~4) | 출력 없이 배포, 수업 중 함께 실행 |
| `weeks/weekNN/assignment.ipynb` | 과제 3~4문제, 자동 확인(✅/❌/⏳) | 학생은 *드라이브에 사본 저장* 후 작성 |
| `weeks/weekNN/assignment.md` | 과제 안내와 채점 기준 | LMS 과제 공지용 |
| `instructor/solutions/weekNN_solution.ipynb` | 모범답안 (실행 결과 포함) | **학생 배포 금지** |

## 한 주 운영 예 (2시간)

| 시간 | 활동 | 교수자 체크 |
|---|---|---|
| 0:00~0:20 | 슬라이드: 지난주 돌아보기 → 목표 → 개념 | "예상해 보기" 슬라이드에서 답을 바로 말하지 않고 손들기·짝 토론 |
| 0:20~1:05 | 실습 노트북 Level 1~2 함께 실행 | 학생이 **실행 전에 예상**하도록 유도, 오류는 마지막 줄부터 함께 읽기 |
| 1:05~1:40 | Level 3 미니 프로젝트, Level 4 AI 검증 (짝 실습) | 막힌 학생에게는 "가장 작은 입력으로 실행해 보기" |
| 1:40~2:00 | AI 사례 공유, 자기 점검, 과제 안내 | 학생 2~3명의 AI 활용 기록을 익명으로 공유 |

## 과제 채점 절차

1. 학생 노트북을 열어 **다시 시작 및 모두 실행** → 자동 확인 결과 확인
2. 모범답안과 다른 입력으로 함수를 1~2번 더 호출해 하드코딩 여부 확인
3. AI 활용 기록과 코드가 일치하는지, 성찰이 구체적인지 확인
4. [주차별 과제 루브릭](../rubrics/weekly-assignment-rubric.md)으로 채점

> 자동 확인 셀은 학생용 노트북에 그대로 있으므로, 채점자는 **학생이 기대값을 바꾸지 않았는지**도 확인합니다. (원본 `assignment.ipynb`의 확인 셀과 비교)

## 중간 실기 운영 (8주차)

- 실기 전주(7주차)에 8주차 **실습 노트북**(빠른 점검 6문항 + 모의 실기)을 과제로 내주면 효과적입니다.
- 실기 당일 **AI 사용 범위를 먼저 공지**합니다. 예:
  - A안: AI 사용 금지 (Colab 자동 완성 기능 끄기 안내)
  - B안: 개념 질문만 허용 (코드 생성 요청 금지), 사용 내역은 기술 메모에 기록
  - C안: 전면 허용 + 기술 메모에 상세 기록 + 무작위 구술 확인
- 채점은 [중간 실기 루브릭](../rubrics/midterm-rubric.md)을 따릅니다.

## 최종 프로젝트 운영 (12~15주차)

| 주 | 교수자 활동 |
|---|---|
| 12 | 제안서 초안 수합, 연구 질문 피드백 (답할 수 있는가, 비교가 있는가) |
| 13 | 수업 시작 10분: 제안서 공통 피드백, 데이터 선택 확정 |
| 14 | 릴리스 후보 점검표로 개별 점검 (재현성 셀, 작은 테스트, 입력 불변) |
| 15 | 발표 진행 (5분 + 질의 2분), 동료 평가지 배포·수합 |

발표 인원이 많으면 15주차 발표를 두 번에 나누고, 14주차 후반 30분을 발표 리허설로 씁니다.

## 데이터와 환경

- 모든 노트북의 `get_data()`는 `../../datasets/`를 먼저 찾고, 없으면 GitHub raw URL에서 내려받습니다. **저장소 이름이나 기본 브랜치를 바꾸면** 노트북의 `DATA_URL`도 함께 바꿔야 합니다.
- 데이터를 수정하려면 `scripts/make_datasets.py`를 고친 뒤 실행합니다. 자동 확인의 기준값이 바뀌므로 반드시 검증 스크립트로 확인합니다.
- 시각화 주차(12, 13, 15)는 `koreanize-matplotlib`를 자동 설치합니다. Colab 첫 실행 시 약간의 시간이 걸립니다.

## 자료 수정 후 검증

```bash
python -m pip install -r requirements.txt
python scripts/validate.py --execute            # 전체
python scripts/validate.py --execute --weeks 9  # 특정 주차
bash scripts/build_slides.sh 9                  # 9주차 슬라이드 PDF 다시 만들기
```

검증 항목: 파일 존재, 실습 노트북 오류 없음, 모범답안 자동 확인 전부 통과, 학생용 과제 노트북에 미작성 외 오류 없음
