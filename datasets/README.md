# 수업용 데이터셋

모든 데이터는 수업을 위해 만든 **가상 데이터**입니다. 실제 개인·기관 정보가 아니며, 이름은 무작위로 조합했습니다.
[`scripts/make_datasets.py`](../scripts/make_datasets.py)는 시드를 고정했으므로 실행할 때마다 같은 파일이 만들어집니다.

```bash
python scripts/make_datasets.py
```

## students.csv — 학생 성적 (80행)

| 열 | 설명 |
|---|---|
| `student_id` | 학번 (문자열로 읽기 권장) |
| `name` | 이름 (가상) |
| `department` | 학과 5개: 간호학과, 경영학과, 전자공학과, 정보보안학과, 컴퓨터공학과 |
| `year` | 학년 1~4 |
| `midterm`, `final`, `assignment` | 0~100점. `assignment`는 3명 결측(미제출) |
| `attendance` | 출석 횟수 (16회 만점) |

사용: 6주차(CSV 집계), 8주차(중간 실기), 10주차(pandas 탐색), 15주차(데이터 지문)

## students_raw.csv — 오류가 섞인 성적 (18행)

`students.csv`와 같은 열. 이름 누락, 숫자가 아닌 점수(`abc`), 범위 밖 점수(120, −5), 학년 5, 출석 20, 중복 학번, 공백이 섞인 값 등 **8행에 일부러 오류**를 넣었습니다.

사용: 6주차 파일·예외 처리

## survey_raw.csv — 정제 전 설문 (156행)

| 열 | 품질 문제 |
|---|---|
| `response_id` | 완전히 같은 응답 6건 중복 |
| `submitted_at` | `2025-09-03 14:22`, `2025/09/03 14:22`, `2025.09.03 14:22` 형식 혼재 |
| `department` | `컴공`, `보안학과`, `컴퓨터 공학과`, 앞뒤 공백 등 14가지 표기 |
| `grade` | `2`, `2학년`, ` 2 ` |
| `coding_hours` | 하루 코딩 시간. `2시간`, `약 3`, 빈 칸, 이상값(30, 25, −1) |
| `uses_ai` | `예`/`Y`/`yes`/`사용함`, `아니오`/`N`/`no`/`사용안함` |
| `satisfaction` | 1~5. `4점`, 빈 칸 |
| `comment` | 자유 응답 |

사용: 11주차 정제·변환·집계

## departments.csv — 학과 정보 (5행)

`department`, `college`(단과대학), `building`. 사용: 11주차 `merge`

## weather_daily.csv — 일별 기상 (365행, 2025년)

| 열 | 설명 |
|---|---|
| `date` | 2025-01-01 ~ 2025-12-31 |
| `avg_temp`, `max_temp`, `min_temp` | 기온(℃). `avg_temp` 3일 결측 |
| `precipitation_mm` | 강수량(mm), 여름에 많음 |
| `humidity` | 습도(%) |

계절 변화가 있는 가상 기온입니다. 실제 목포 기상 관측값이 아닙니다.
사용: 9주차(NumPy), 12~15주차(카페 판매와 결합)

## cafe_sales.csv — 캠퍼스 카페 판매 (3,019행)

| 열 | 설명 |
|---|---|
| `order_id` | 주문 번호 |
| `date`, `time` | 2025-03-03 ~ 2025-06-20, 08~19시. **일요일 휴무** |
| `menu`, `category` | 메뉴 11종, 분류(커피·논커피·디저트) |
| `temp_type` | `HOT` / `ICE` / `-`(디저트) |
| `unit_price`, `qty` | 단가(아이스는 300원 추가), 수량 |
| `payment` | 카드·모바일·현금 |

**한 행 = 주문 한 건의 메뉴 한 종류**입니다. 데이터에 넣어 둔 패턴:
- 평일 점심(12~13시)에 주문이 몰림, 토요일은 평일의 절반 이하
- 시험 주간(2025-04-21~25, 06-16~20)에 주문 증가
- 기온이 높을수록 아이스 음료 비율 증가 (`weather_daily.csv`와 날짜로 결합)

사용: 12주차(EDA), 13주차(시각화), 14주차(디버깅), 15주차(최종 예시)
