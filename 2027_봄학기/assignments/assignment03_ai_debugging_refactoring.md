## 2. 과제 목적

오류 없이 실행되지만 결과가 틀린 **조용한 버그**를 찾고, 버그를 잡는 **테스트**를 만들고, 결과를 바꾸지 않으면서 코드를 **리팩토링**합니다. AI에게 디버깅을 맡길 때는 좋은 질문을 하고, 그 답을 검증합니다.

## 4. 수행 방법

1. 위 링크로 노트북을 열고 **파일 → Drive에 사본 저장** 후 이름을 바꿉니다.

3. 손으로 답을 알 수 있는 **작은 입력**부터 실행합니다.

### AI에게 디버깅을 요청하는 좋은 질문 (문제 4)

```text
아래 함수는 날짜별 아이스 음료 비율(%)을 판매 수량 기준으로 구해야 합니다.
[최소 재현 코드 + 작은 데이터]
기대 결과: 2025-03-03 → 60.0
실제 결과: 2025-03-03 → 33.3
원인을 먼저 줄 단위로 설명하고, 수정은 최소한으로 해 주세요. 입력 DataFrame은 바꾸면 안 됩니다.
```

> AI가 **테스트를 고치자고 하거나**, 특정 입력일 때만 정답을 돌려주는 코드를 주면 의심하세요. 두 번째 테스트 데이터로 꼭 다시 확인합니다.
