## 2. 과제 목적

자료구조, 조건문, 반복문, 함수, 파일·CSV 처리, 예외 처리, 클래스를 **하나의 프로그램**으로 통합합니다. 실행되는 코드를 만드는 데서 끝나지 않고, 규칙과 경계값을 테스트해 결과가 정확한지 설명해야 합니다.

## 3. 문제 상황

교수자는 학생 80명의 성적 파일 `students.csv`로 다음을 자동 계산하는 프로그램이 필요합니다.

- 잘못된 행을 걸러 낸 학생 목록
- 규정에 따른 총점과 최종 등급, 학과별 요약
- 상위 학생, 등급 분포, 위험(F) 학생 조회
- 한눈에 보는 보고서 파일

### 성적 규정

| 항목 | 규정 |
|---|---|
| 총점 | 중간 30% + 기말 40% + 과제 30%, 소수 첫째 자리 반올림 |
| 과제 미제출 | 빈 칸 → `None`, 총점 계산에서는 0점 |
| 등급 | 90 이상 A, 80 이상 B, 70 이상 C, 60 이상 D, 그 외 F |
| 출석 | 16회 중 12회 미만이면 총점과 관계없이 F |

## 4. 문제 구성

| 문제 | 내용 | 배점(노트북 기준) | 관련 주차 |
|---|---|---:|---|
| 1 | `load_students`: CSV 읽기, 형 변환, 규칙 위반 행 건너뛰기 | 20 | 6주 |
| 2 | `total_score` · `final_grade` · `dept_summary` | 25 | 3·4·5주 |
| 3 | `GradeBook` 클래스: 찾기, 상위 n명, 등급 분포, 위험 학생 | 25 | 4·7주 |
| 4 | `write_report`: 정해진 형식의 보고서 파일 | 20 | 2·6주 |
| 5 | 기술 메모: 설계·테스트·AI 사용·한계 | 10 | 전체 |

각 문제의 자세한 요구사항과 **자동 확인 셀**은 노트북에 있습니다.

## 5. 수행 방법

1. 위 링크로 노트북을 열고 **파일 → Drive에 사본 저장** 후 이름을 바꿉니다.
2. 맨 위 "준비" 셀을 실행합니다.
3. 문제 1부터 순서대로 `# TODO`를 채우고, 문제 아래 자동 확인 셀이 ✅인지 확인합니다. 문제 2~4는 문제 1의 결과를 사용합니다.
4. 자동 확인 외에 **직접 고른 경계·오류 사례**를 한두 개 더 실행해 봅니다. (예: 출석 11/12회, 총점 89.95, 과제 빈 칸)

## 6. 규칙

- **pandas는 사용하지 않습니다.** Python 표준 라이브러리(`csv`, `pathlib` 등)로 작성합니다.
- AI는 사용할 수 있습니다. 단, 기술 메모의 **AI 사용** 항목에 도구·질문·채택·수정 내용을 기록하고, 제출한 코드를 한 줄씩 설명할 수 있어야 합니다.
- `except:`처럼 모든 오류를 삼키는 코드는 쓰지 않습니다.
- 결과값을 직접 써 넣어 자동 확인만 통과시키면 해당 문제는 0점입니다.
