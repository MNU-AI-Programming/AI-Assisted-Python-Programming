## 2. 과제 목적

데이터로 답할 수 있는 **연구 질문**을 세우고, 데이터를 **정제·분석·시각화**해 **근거 있는 결론과 한계**를 제시합니다. 다른 사람이 노트북을 **다시 실행해 같은 결과**를 얻을 수 있어야 하며, AI를 어떻게 쓰고 검증했는지 공개합니다.

## 3. 데이터 선택

## 4. 필수 수행 단계

[템플릿 노트북](https://colab.research.google.com/github/MNU-AI-Programming/AI-Assisted-Python-Programming/blob/main/templates/final_project_template.ipynb)의 절 순서를 그대로 따릅니다.

### 단계 0. 재현성 셀

- 라이브러리 버전, 난수 시드, 데이터 지문(파일 크기·해시)을 노트북 맨 위에 출력합니다. (템플릿에 들어 있음)

### 단계 1. 연구 질문

- 데이터로 답할 수 있고 **비교 대상**이 있는 질문을 **2개 이상** 작성합니다.
- ❌ "카페 매출을 분석한다" → ✅ "평일 점심 매출은 다른 시간대보다 얼마나 높은가?"

### 단계 2. 데이터 이해

- 출처, **한 행의 의미**, 기간, 행·열 수, 자료형, 결측·중복을 코드와 설명으로 제시합니다.

### 단계 3. 정제·파생 변수

- 정제 계획을 표로 쓰고(열 / 문제 / 처리 / 이유), 정제는 **함수로**(입력 불변) 작성합니다.
- 정제 전후의 행 수, 결측 수 등을 비교표로 보여 줍니다.

### 단계 4. 분석과 테스트

- 질문마다 pandas 필터·정렬·`groupby`·`pivot_table` 등으로 결과표를 만듭니다.
- 그룹마다 일수·인원이 다르면 **합계가 아닌 평균(일평균 등)** 으로 비교합니다.
- 핵심 계산 함수 하나 이상에 **손으로 답을 아는 작은 데이터 테스트**를 붙입니다.

### 단계 5. 시각화

서로 다른 목적의 그래프를 **3개 이상** 작성합니다.

- 모든 그래프: **결론을 담은 제목**, 축 이름과 **단위**, 필요하면 범례
- 막대 그래프는 **0부터**, 순서가 의미 있게, 색은 강조할 때만
- 그래프 아래에 2문장 이상의 해석

### 단계 6. 결론과 한계

- 질문별 결론을 **숫자 근거**와 함께 씁니다.
- 한계를 두 가지 이상 씁니다. (가상 데이터, 기간, 표본 크기, **상관과 인과의 구분** 등)

### 단계 7. AI 활용 공개

AI가 작성하거나 제안한 코드·문장 중 **하나 이상**을 골라 다음 표를 작성합니다.

| 항목 | 기록 내용 |
|---|---|
| 사용한 프롬프트 | AI에 실제 입력한 내용 |
| AI의 제안 | 코드, 분석 방법 또는 결론 문장 요약 |
| 의심 지점 | 집계 단위(건수/수량), 합계 vs 평균, 인과 표현, 결측 처리 등 |
| 검증 방법 | 작은 데이터 손계산, 다른 pandas 명령과 비교, 표와 그래프 값 대조 |
| 직접 수정 | 변경 전·후와 이유 |
| 최종 판단 | 채택 / 일부 채택 / 거절 |

### 단계 8. 재현성 확인

- **런타임 → 다시 시작 및 모두 실행**으로 데이터 불러오기부터 결론까지 한 번에 실행되는지 확인합니다.
- 내 Google Drive 같은 개인 경로를 쓰지 않습니다.
