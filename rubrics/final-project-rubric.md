## 체크리스트 (제출 전 학생 자가 점검)

- [ ] 연구 질문 2~3개가 노트북 맨 앞에 있다
- [ ] 재현성 셀(버전·시드·데이터 지문)이 있다
- [ ] *다시 시작 및 모두 실행*에서 오류가 없다
- [ ] 정제·분석은 함수로 되어 있고, 핵심 계산에 작은 테스트가 있다
- [ ] 그래프마다 결론형 제목과 단위가 있다
- [ ] 결론마다 근거와 한계가 있다
- [ ] README, 발표 자료, AI 활용 기록, 성찰 보고서가 있다
