# 중간 실기 루브릭 (100점)

## 영역별 비중

| 영역 | 비중 | 확인 방법 |
|---|---:|---|
| 기능 | 60% | 자동 확인 셀, 채점자의 추가 입력 실행 |
| 코드 품질 | 20% | 함수 분리, 이름, 중복, 예외 처리 방식, 입력 불변 |
| 검증 | 10% | 직접 추가한 경계·오류 확인 |
| 기술 메모 | 10% | 설계·테스트·AI 사용·한계 |

## 문제별 채점 기준

### 문제 1. 데이터 읽기와 검증 (20점)

| 항목 | 점수 | 기준 |
|---|---:|---|
| 형 변환 | 6 | 숫자 열은 `int`, 과제 빈 칸은 `None` |
| 행 검증 | 8 | 규칙(필수 값, 점수·출석·학년 범위)을 어긴 행만 건너뜀 |
| 건너뛴 행 수 | 3 | 정확히 셈 |
| 예외 처리 방식 | 3 | `ValueError` 등 구체적인 예외만 처리 |

### 문제 2. 성적 계산과 학과별 요약 (25점)

| 항목 | 점수 | 기준 |
|---|---:|---|
| 총점 | 7 | 가중치, 과제 `None` → 0점, 반올림 |
| 최종 등급 | 8 | 경계값(90.0 등), 출석 규정(12회) |
| 학과 요약 | 10 | 인원·평균·통과율, 가나다순 |

### 문제 3. `GradeBook` 클래스 (25점)

| 항목 | 점수 | 기준 |
|---|---:|---|
| `find` · `__len__` | 5 | 없는 학번은 `None` |
| `top` | 7 | 총점 내림차순, 동점 학번순 |
| `distribution` | 6 | 5개 키 모두, 0명 등급 포함 |
| `at_risk` | 5 | F 학생, 총점 오름차순 |
| 입력 불변 | 2 | 입력 리스트를 바꾸지 않음 |

### 문제 4. 보고서 파일 (20점)

| 항목 | 점수 | 기준 |
|---|---:|---|
| 형식 | 10 | 7줄, 줄별 형식 정확 |
| 계산 재사용 | 6 | 앞 문제의 함수로 계산, **하드코딩 없음** |
| 예외 상황 | 4 | 위험 학생 0명, 학생 0명(`ValueError`) |

### 문제 5. 기술 메모 (10점)

| 항목 | 2.5점 | 1점 | 0점 |
|---|---|---|---|
| 설계 | 분리 이유가 구체적 | 구조만 나열 | 없음 |
| 테스트 | 자동 확인 외 사례를 실제 값과 함께 | 일반론 | 없음 |

## 감점

| 상황 | 감점 |
|---|---|
| 결과 하드코딩 | 해당 문제 기능 점수 0 |
| *다시 시작 및 모두 실행* 오류 | 오류 이후 문제 기능 점수 50% |
